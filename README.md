# tictactoe-educativo
TicTacToe Educativo combina la estrategia del tres en raya con preguntas de conocimiento para aprender de forma divertida e interactiva. Pon a prueba tus conocimientos, desarrolla tu pensamiento lógico y compite respondiendo correctamente. ¡Aprende, juega y demuestra lo que sabes en español o inglés!
